# Niplex — NEVER STOP IMAGINING

Open-source documentation home of **Niplex** — Adarsh Jaiswal's collection of
AI agent systems, MCP tooling, and independent projects.

Built with **MkDocs** (Material theme) and published on **Read the Docs**.

## Live docs

Coming soon at `https://aj-niplex.readthedocs.io/`

## Quick start

```bash
# Install build dependencies
pip install -r requirements.txt

# Run a local dev server
mkdocs serve

# Build the static site into site/
mkdocs build
```

## Repository layout

```
docs/            # All documentation content (Markdown)
  assets/        # Logos and images
  projects/      # Per-project documentation pages
  blog/          # Blog index and posts
  stylesheets/   # Custom theme (Japan/India split brand identity)
  javascripts/   # Animations and MathJax config
mkdocs.yml       # MkDocs + Material theme configuration
.readthedocs.yaml# Read the Docs build configuration
requirements.txt # Build dependencies
legacy/          # The original static HTML portfolio site (archived)
```

## Features

- Animated hero with split **Japan (sakura) → India (saffron/green)** brand gradient
- Material card grids, scroll-reveal animations, instant navigation
- Social cards (auto-generated per-page OG images)
- Page feedback widget + Google Analytics (fill in your `G-` ID in `mkdocs.yml`)
- Blog, FAQ, and topic tags
- Versioned docs (via Read the Docs versions feature)
