What NiPlex Is

The Collection

NiPlex is the product collection of Adarsh Jaiswal (AJ NiPlex) — independent, self-hosted, and built around AI agents that do real work. Two flagships lead it: NiPlex-Harness, the phone-first agent harness, and NiPlex-MCP, the 73-tool production MCP server.

The Method

Backend and agents first. AI tools are used deliberately in the process — three agent lanes (Claude, Grok, Mistral) work the codebase under human direction — but the judgment, architecture and shipping decisions belong to the owner. Social apps are the primary UI, not a web dashboard.

The Stack

Python 3.13 · MCP Protocol · Discord.py · aiohttp · Linux VPS · sandbox isolation · agent memory layers. Free-host friendly (HidenCloud, Horizon, Wispbyte) by design — everything here runs on infrastructure that costs nothing.
