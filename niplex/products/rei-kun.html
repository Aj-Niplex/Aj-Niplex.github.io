Rei-kun Bot

The live Discord AI orchestrator — persona, fallback models and a hard security layer

What It Is

Rei-kun is a persona-driven Discord AI orchestrator serving an active student community — not a demo bot, a deployed one. It chats, diagnoses code, curates study resources and manages its own community, while a serious security layer (rate limiting, RBAC, ToS tracking, blocklists) keeps a public-facing bot safe.

Its identity lives in config/bot_identity.yaml — the persona is a config file, so tone and character change without touching code. The brain is app.py (19KB core), supported by 21 utility modules and a core package that owns ownership, prompting, rate limiting and security.

Multi-Model Fallback

Rei-kun routes chat through OpenRouter with multi-model fallback: if the primary model fails or times out, the next in the chain takes over mid-conversation. The community never sees a dead bot — it sees a slightly different voice at worst. Claude integration is used for heavier reasoning through utils/ai.py.

Code Doctor

The signature feature: paste broken Python, get a diagnosis plus a patched version. It reads the error, explains what went wrong in plain language, and returns corrected code — purpose-built for the student community it serves.

Security Layer

  • Rate limiting — per-user quotas via core/rate_limiter.py, so no one can flood the AI budget.
  • Input sanitization — user text is cleaned before it reaches any model or file.
  • RBAC — permissions module gates admin commands by role.
  • ToS tracking — tos.py records consent per user before elevated features unlock.
  • Blocklists — blocked_users JSON store keeps banned users out at the data layer.
  • Secret hygiene — encrypt_secrets.py keeps credentials encrypted at rest.
  • SMTP error alerts — email_sender.py emails the owner when the bot errors, plus vps_logger.py for host-side visibility.
