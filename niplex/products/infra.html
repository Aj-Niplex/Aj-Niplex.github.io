Infrastructure

The quiet utilities that keep a zero-cost ecosystem running

What This Is

NiPlex runs on infrastructure that costs nothing — free hosts, free LLM tiers, self-built sandboxes. This is the layer that makes that possible: a free LLM gateway, a self-hosted code sandbox, a cron reminder worker, an OpenDots host launcher, plus the docs and coordination repos that keep three AI-agent lanes working the same codebase without stepping on each other.

Free LLM Gateway (niplex-worker)

An OpenAI-compatible endpoint for the whole ecosystem, assembled from free tiers and gated by one key:

  • Caddy reverse proxy in front of FreeLLMAPI (Wispbyte free tier), with a PUBLIC_API_KEY gate on the public route
  • Model "auto" — one name routes to whatever is available
  • Providers: Groq, Google AI Studio, OpenRouter — all free tiers
  • Runs on port 8080; FreeLLMAPI's dashboard stays localhost-only
  • One command to run: bash start.sh

Self-Hosted Code Sandbox

A FastMCP run_code server built for one reason: stop paying for E2B and Daytona when a controlled own-host sandbox does the job.

  • Runs Python and JavaScript
  • Hard limits: 60s wall clock · 1.5GB RLIMIT_AS · 50K output chars
  • Subprocess with full internet + environment passthrough — documented honestly, including the secrets caveat that implies
  • A health tool for monitoring

worker-server — Cron + Reminders

A standalone poller that reads tasks from notion-mcp, evaluates cron and reminder rules on each pass, and sends reminder emails when something is due. No framework ceremony — one loop, one job.

opendots-host

A launcher that downloads, builds and runs CopilotKit's OpenDots on HidenCloud — including a gemini-shim.js to adapt model calls and an index.js entry. Proof the pattern generalizes: NiPlex can host and adapt third-party agent UIs, not just its own.

The Zero-Cost Principle

costs.txt
HidenCloud (free VPS tier)   — harness, Rei-kun, workers
Horizon (free container)     — NiPlex-MCP, Neural-MCP, sandbox
Wispbyte (free hosting)      — FreeLLMAPI behind Caddy
Groq / AI Studio / OpenRouter — free LLM tiers via gateway
GitHub Pages                  — this site

Monthly infrastructure bill: $0

Everything in this directory runs on infrastructure that costs nothing — by design, not by accident. The constraint shaped the architecture: gateways instead of paid APIs, own-host sandboxes instead of metered ones, and always a fallback chain.
