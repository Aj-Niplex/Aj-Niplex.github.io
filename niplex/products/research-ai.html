Niplex Research AI

The autonomous Obsidian research agent — bounded context, transparent prompts, approved edits

What It Is

Niplex Research AI is a real Obsidian plugin — not a script that happens to touch Markdown files. It ships with manifest.json, versions.json, an esbuild build pipeline and a test suite, and it runs inside Obsidian, which makes it the most mobile-first product in the collection: research sessions start from the same app that already holds the vault, on the phone.

Its job is autonomous research: given a topic, it plans, reads what it needs, and drafts — under three hard rules: bounded reads (line windows, never whole vault), transparent prompts (the system prompt is inspectable), and approval-gated edits (durable changes wait for a human yes).

The src/core Module Map

The plugin's discipline shows in its architecture — every concern gets its own module in src/core:

ModuleResponsibility
agent-runtime.tsThe research agent loop itself
approval-policy.tsWhat needs a human yes before it is durable
context-budget.tsBounded line-window reads — the vault is never read whole
chat-history.tsSession history for long research runs
mcp-client.ts + mcp-compat.tsConnecting out to MCP servers (with compatibility layer)
model-fallback.tsTry the good model, fall back to the reliable one
system-prompt.tsTransparent, inspectable prompts
vault-context.tsVault-aware retrieval for research grounding
moc-organizer.tsMaps of Content — auto-organizing the vault's index notes
youtube.tsResearch from YouTube sources

Why It Matters in the Collection

Every NiPlex product enforces the same three ideas — bounded context, explicit approvals, transparent prompts — but Research AI enforces them against the most personal surface of all: the knowledge vault. It is the proof that an agent can be genuinely autonomous inside someone's notes without ever being trusted blindly.

Install

install.txt
# From the repo
npm install
npm run build      # esbuild pipeline
# copy manifest.json + main.js into
# .obsidian/plugins/<plugin-id>/ in your vault
# enable in Obsidian settings → Community plugins
