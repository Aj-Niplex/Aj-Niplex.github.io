# FAQ

Quick answers about Niplex, our projects, and how to use them.

## About Niplex

??? question "What is Niplex?"

    Niplex is a technology company rooted in AI, Machine Learning, and code,
    dedicated to empowering non-technical users. Our mission is to shift the
    burden of heavy thinking and repetitive tasks to AI systems. Everything we
    build is open source.

??? question "What does 'Never stop Imagining' mean?"

    It's our mission statement. We believe the human role in the AI era is to
    think, imagine, and strategize — while our systems handle the heavy
    lifting of processing, automating, and executing.

??? question "Who is behind Niplex?"

    Niplex is built by Adarsh Jaiswal, a Class 12 PCM student working toward
    the MEXT Undergraduate Scholarship to study Robotics Engineering in Japan.
    Read more on the [Vision](about.md) page.

## About the projects

??? question "Are the projects really open source?"

    Yes. Every project listed on the [Projects](projects/index.md) page is
    public and inspectable. Private work stays private and is never listed
    here.

??? question "What is Model Context Protocol (MCP)?"

    MCP is a standard protocol that lets AI agents talk to external tools and
    infrastructure securely. Our [Niplex-MCP](projects/niplex-mcp.md) project
    is a full implementation. There's also a
    [gentle introduction in the blog](blog/posts/mcp-intro.md).

??? question "What is Rei-kun?"

    Rei-kun is a production Discord bot serving an active student community.
    It uses a multi-model fallback engine and a study resource hub. See the
    [Rei-kun Bot](projects/rei-kun.md) documentation.

??? question "How do I use one of your projects?"

    Each project has its own documentation page with install and setup
    instructions — look under **Projects** in the navigation, or check the
    repository's README on GitHub.

## About this site

??? question "Is this documentation site open source too?"

    Yes. The site itself is a public repository:
    [Aj-Niplex/Aj-Niplex.github.io](https://github.com/Aj-Niplex/Aj-Niplex.github.io).
    You can read it, fork it, or propose changes.

??? question "How is this site built?"

    It's built with [MkDocs](https://www.mkdocs.org/) and the
    [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) theme,
    and published on Read the Docs. All content is Markdown.
