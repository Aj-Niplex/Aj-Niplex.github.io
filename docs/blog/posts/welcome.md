Welcome to the new home of Niplex. This site used to be a single-page
portfolio — now it's a full open-source documentation project, published on
Read the Docs.

## Why we rebuilt it

Three reasons:

1. **Promotion.** A documentation site reads as serious, long-term work.
   Projects, architecture, and roadmap — all in one public place.
2. **Open source.** Every project we list here is public and inspectable.
   Private work stays private.
3. **Maintainability.** Markdown is easy to edit, version-controlled, and
   builds into a fast, searchable site.

## What's here

- **Mission & Vision** — who we are and where we're going.
- **Projects** — the always-current list of public repositories, each with
  its own documentation page.
- **Blog** — articles and progress updates (you're reading one).
- **FAQ** — quick answers to common questions.
- **Roadmap** — the path from Gorakhpur to a robotics lab in Japan.

## What's next

More project deep-dives, more tutorials on AI tooling, and regular progress
posts. If there's something you'd like us to write about, open an
[issue on GitHub](https://github.com/Aj-Niplex/Aj-Niplex.github.io/issues).
