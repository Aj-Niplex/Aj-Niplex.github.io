## What It's For

Neural-OS is an early-stage project to coordinate multiple AI agents together
— how they share memory, hand off tasks, and decide which model handles what.
Rei-kun already uses a simple version of this idea (multi-model fallback);
Neural-OS is the attempt to generalize that into something reusable.

This is currently a **design exercise, not shipped code**. I'm working through
the architecture before writing the implementation.
