## What It Is

This repository contains the source for this documentation site. It's built
with **MkDocs** and the **Material for MkDocs** theme, and published on
**Read the Docs** — a fully open-source project, just like everything else in
the Niplex collection.

## Tech Stack

- **MkDocs** — static site generator
- **Material for MkDocs** — theme (light/dark mode, search, code copy)
- **Read the Docs** — free open-source hosting
- **Markdown** — all content is plain, version-controlled text

## Repository Layout

```
docs/            # All documentation content (Markdown)
  assets/        # Logos and images
  projects/      # Per-project documentation pages
mkdocs.yml       # MkDocs + Material theme configuration
.readthedocs.yaml# Read the Docs build configuration
requirements.txt # Build dependencies
legacy/          # The original static HTML portfolio site (archived)
```
