## Status

**Starter template** — a reusable foundation for files-first AI memory.

## What It Is

A files-first AI memory workspace designed to survive fresh chat sessions.
Everything important is stored as plain files that any AI agent (or human)
can read, so context persists between conversations instead of living only in
a chat window.
